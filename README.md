# 부트캠프 경진대회

## Microsoft 주제 · Re AI 개발기

> 산업폐기물과 부산물의 재활용 경로를 찾는 AI 서비스 | 4인 팀 프로젝트 | 개발 중

### 왜 이 주제를 골랐나

산업현장에서 나온 부산물을 다른 기업이 원료로 쓸 수 있을지 판단하려면, 그 기업이 요구하는 규격과 실제 부산물의 품질, 오염 상태를 함께 확인해야 합니다. 저희 팀은 “이 부산물을 어디에 쓸 수 있을까?”와 “조건이 맞지 않는다면 무엇을 확인해야 할까?”라는 질문에서 시작했습니다.

Re AI는 이런 조건을 확인하고, 해당 부산물을 활용할 수 있는 업종이나 재활용 경로를 찾는 데 도움을 주는 서비스입니다.

### 내가 맡은 일

저는 사용자가 AI와 대화하는 화면과, 대화 중 작성한 문서를 다시 찾아볼 수 있는 문서함의 흐름을 설계했습니다. 사용자가 채팅에서 요청서를 작성한 뒤 나중에 다시 들어와도 찾기 쉽게 하려면, 대화 화면과 문서함이 어떻게 연결돼야 할지 고민했습니다.

팀원들이 만든 에이전트를 한 웹서비스에 연결하기 위해 Azure에서 서버를 실행할 환경도 준비하고 있습니다.

### 지금까지 확인한 것

회원가입 과정에서 인증 메일이 발송되고 이메일 인증이 완료되는 것을 확인했습니다. Azure 배포를 준비하는 과정에서는 GPU VM을 생성할 때 할당량 제한이 표시돼, 교육 계정에서 추가 할당을 받을 수 있는지 문의했습니다.

### 다음에 확인할 것

다음에는 채팅에서 작성한 요청서를 문서함에 저장한 뒤, 다시 로그인해도 열 수 있는지 확인하려고 합니다. 계정 두 개로 테스트해서 각자 저장한 대화와 문서가 본인 계정에서만 보이는지도 확인할 계획입니다.

### UI/UX 구현

제가 맡은 부분은 **AI 채팅 화면과 문서함의 사용자 흐름**입니다. 채팅 화면에서는 사용자가 부산물에 대해 질문하고, 앞서 나눈 대화를 보면서 후속 질문을 이어갈 수 있도록 구성했습니다. 문서함은 대화 중 작성한 요청서를 나중에 다시 찾아볼 수 있도록 설계했습니다.

| 코드 | 담당 기능 |
| --- | --- |
| `frontend/src/App.tsx` | 메인 화면 구성, 채팅과 문서함 화면 전환 |
| `frontend/src/style.css` | 화면 배치, 색상, 버튼 등 공통 스타일 |
| `frontend/src/lib/api.ts` | 프론트엔드에서 백엔드 API를 호출하고 응답을 받는 코드 |

GitHub에 올린 코드는 React와 TypeScript로 작성한 프론트엔드입니다. 실제 AI 답변이나 문서 저장 기능을 사용하려면 FastAPI 백엔드도 실행해야 합니다.
